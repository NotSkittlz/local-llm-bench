How to read this

  • TTFT is client-observed time to first content token. It includes queueing, prefill, and the first decode step.
  • Decode tok/s excludes that first token: (output tokens − 1) / (last token − first token).
  • Prefill tok/s uses server prompt timings when present; otherwise it is the proxy prompt_tokens / TTFT.
  • p50 / p95 are linear-interpolation percentiles over successful measured trials (warmup discarded).
  • Harness overhead is the client floor measured against a zero-delay mock. Subtract it from TTFT for a lower bound on server time.
  • VRAM is device-level when NVML/nvidia-smi is available, sampled on a niced background thread (~4 Hz, 1 Hz for nvidia-smi).
